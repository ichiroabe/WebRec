# WebRec

画面操作を記録し、再現可能なスクリプト（Playwright / Puppeteer / JSON）として出力・管理する Chrome 拡張機能（Manifest V3）です。

## 機能

- 拡張機能アイコンの「記録を開始」を押すと、その時点で表示していたページの URL を**開始URL**として記録を開始します。
- クリック、テキスト入力、セレクトボックス選択、Enter/Escape キー入力、ページ遷移（SPA の履歴遷移含む）を自動で記録します。
- 記録中はページ右上に「WebRec 録画中」のインジケーターが表示され、そこからも停止できます。
- 「記録を停止して保存」を押すと、記録内容がブラウザ内の IndexedDB に保存されます。
- 管理画面（拡張機能アイコン → 「スクリプト管理を開く」、または拡張機能の「オプション」）から、保存済みの録画を一覧・名前変更・削除できます。
- 各録画は次の形式で出力できます。
  - **Playwright**（`@playwright/test` 形式）
  - **Puppeteer**
  - **JSON**（ステップの生データ）
  - コピー / ファイルダウンロードが可能です。
- 管理画面から「▶ 再生」を押すと、拡張機能自体が新しいタブを開き、記録した操作を実際に再現します（進捗をステップごとに表示）。

## インストール方法（開発者モードで読み込み）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、この `WebRec` フォルダを選択する

## 使い方

1. 記録したいページを開き、拡張機能アイコンをクリックして「● 記録を開始」を押す
2. 通常どおりページを操作する（クリック・入力・遷移など）
3. アイコンを再度開き「■ 記録を停止して保存」を押す、またはページ右上のインジケーターの「■ 停止」を押す
4. 「管理画面で開く」から、保存された録画の一覧・スクリプト出力・再生ができる

## データの保存場所

録画データはブラウザのプロファイル内 IndexedDB（`webrec-db`）に保存されます。外部サーバーへの送信は一切行いません。

## 記録できる操作

- クリック（ボタン、リンク、チェックボックス、ラジオボタン、label など）
- テキスト入力 / テキストエリア（`change` で確定値のみ記録するため、途中の打ち直しや訂正は記録されません）
- セレクトボックス（単一選択・複数選択の両方）
- Enter / Escape キー
- HTML5 のドラッグ&ドロップ（左右リスト間の項目移動など）
- ファイルアップロード（`<input type="file">`。下記参照）
- iframe 内の上記すべての操作（どの iframe 内かも併せて記録し、再生・スクリプト出力に反映されます）
- ページ遷移（通常遷移と SPA の history 遷移。連続発火はデバウンスして 1 件にまとめます）

## JSON がスクリプトの本体

記録内容の実体は JSON です。Playwright / Puppeteer 出力は、この JSON から生成される「書き出し形式」にすぎません。

管理画面の詳細ダイアログ →「JSON（編集可）」タブで直接編集し、「保存」でその録画に反映できます。保存前に検証され、問題があれば `steps[3].selector がありません` のように具体的な箇所が表示されます（壊れた状態では保存されません）。

**「ステップ一覧」の各行をクリックすると、JSON タブに切り替わってそのステップが選択状態で表示されます。** 先頭の「開始URLを開く」行からは `startUrl` へ移動します。直したいステップを一覧で見つけて、そのまま編集できます。

### 検証（整合性チェック）

JSON タブの「検証」ボタン（および JSON タブを開いたとき・保存時・インポート時）に、**JSON として正しいかだけでなく、シナリオとして辻褄が合っているか**を確認します。指摘をクリックすると該当ステップへ移動します。

**エラー**（これがあると保存できません）

| 内容 | 例 |
| --- | --- |
| データに無い列の参照 | `{{data.名前}}` と書いたが、データにあるのは `氏名` |
| データが無いのに `{{data.○○}}` を使用 | 「データ」タブが空 |
| セレクタとして解釈できない | `###` など |
| `timeoutMs` / `waitBeforeMs` / `ms` が数値でない・負の値 | `"timeoutMs": "abc"` |
| `navigate` の URL が http/https でない | `ftp://…` |

**警告**（保存はできますが要確認）

| 内容 | 例 |
| --- | --- |
| 未対応の変数 | `{{today}}`（そのまま文字列として入力されます） |
| パスワードが未設定のまま | 値が `<PASSWORD>` のまま |
| データの行によって列が欠けている | 1行目に `b` があり 2行目に無い |
| ステップが空 / 全ステップが無効 | — |
| 複数選択の値が空 | `"values": []` |

**情報**

- どのステップからも参照されていないデータ列
- 無効化されたステップへの `optional` 指定（効きません）

エラーの指摘には「ある列: 氏名, 年齢」のように**実在する候補が併記される**ので、打ち間違いをその場で直せます。

- **名前の変更**: 一覧の名前欄をクリックして直接編集できます（Enter で確定 / Esc で取り消し）。空の名前は保存されず、前後の空白は自動で取り除かれます。
- **エクスポート**: 詳細ダイアログの「ダウンロード」で 1 件ずつ。ヘッダーの「全件エクスポート」で全録画を 1 ファイルに。
- **インポート**: ヘッダーの「インポート」から JSON ファイルを選択。1 件形式・全件エクスポート形式・素の配列のいずれも受け付けます。既存の録画を上書きしないよう、取り込み時は常に新しい ID を採番します。

## ファイルアップロード

`<input type="file">` に対応しています。OS のファイル選択ダイアログ自体は自動化できませんが、**記録時に選んだファイルの中身を取り込んでおき、再生時に入力欄へ直接流し込む**ことで同じ状態を再現します。ダイアログは開きません。

- 記録: 普段どおりファイルを選ぶだけです。ファイル名だけでなく**中身も保存**されます（1ステップあたり合計 8MB まで）。
- 再生: 保存した中身から `File` を組み立てて `input.files` にセットし、`input` / `change` を発火します。ページ側からは利用者が選んだのと区別がつきません。
- 複数選択（`multiple`）、選択の解除にも対応しています。

**注意点**

- ファイルの中身は録画データとして IndexedDB に保存され、**JSON エクスポート時にも埋め込まれます**。機密ファイルを扱う場合はエクスポート先にご注意ください。
- 8MB を超えるファイルは中身が保存されず、検証でエラーとして表示されます。
- ドラッグ&ドロップによるアップロードは未対応です（`<input type="file">` のみ）。

**書き出したスクリプトで使う場合**

Playwright / Puppeteer はローカルのファイルパスを受け取る方式のため、出力は `setInputFiles('./files/請求書.pdf')` の形になり、必要なファイル名が先頭のコメントに一覧されます。実ファイルは、管理画面のステップ一覧にある「⭳ ○○ を保存」から取り出して `files/` に置いてください。

## 入力値に使える変数（本日日付など）

`value` や `url` に `{{...}}` を書くと、**再生のたびに実行時の値へ置き換わります**。記録した日付が固定されないので、同じ録画を毎日使い回せます。

| 書き方 | 結果の例（2026-08-27 14:05 に実行した場合） |
| --- | --- |
| `{{date}}` | `2026-08-27` |
| `{{date:YYYY年MM月DD日}}` | `2026年08月27日` |
| `{{date:YYYY}}` / `{{date:MM}}` / `{{date:DD}}` | `2026` / `08` / `27`（年・月・日が別欄のフォーム向け） |
| `{{date:M}}` / `{{date:D}}` | `8` / `27`（0埋めなし） |
| `{{date:YYYY-MM-DD\|+1d}}` | `2026-08-28`（`+1d` `-3d` `+2w` `+1m` `-1y`） |
| `{{time:HH:mm}}` | `14:05` |
| `{{datetime}}` | `2026-08-27 14:05:09` |
| `{{random:0000}}` | `0473`（0埋め4桁。`####` なら0埋めなし） |
| `{{random:1-100}}` | `57`（範囲指定） |
| `{{seq}}` | `42`（再生のたびに1増える通し番号。0埋めなし） |
| `{{seq:000}}` | `042`（同じ番号を0埋め3桁で） |
| `{{uuid}}` | `3f2b...`（ランダムなUUID） |

書式の指定は `:` の後ろ、オプションは `|` で区切ります（`{{time:HH:mm}}` のように書式中の `:` はそのまま使えます）。

**数字の書式（`{{seq}}` `{{row}}` `{{random}}` 共通）**

| 書き方 | 結果 | 用途 |
| --- | --- | --- |
| `{{seq}}` | `42` | 通常の連番（0埋めなし） |
| `{{seq:#}}` / `{{seq:####}}` | `42` | 同上（`#` は桁数を強制しない） |
| `{{seq:000}}` | `042` | 3桁に0埋め |
| `{{seq:00000}}` | `00042` | 5桁に0埋め |

`0` の個数がそのまま桁数になります。値が桁数を超える場合は切り捨てずそのまま出力されます（`{{seq:00}}` で値が 12345 なら `12345`）。

`{{seq}}` の現在値は「⚙ 設定」で確認・変更できます。1 を入れると次の再生から振り直しになります。

- 日付と連番は**1回の再生を通して同じ値**になります（画面をまたいでも年月日がずれません）。
- 未対応の変数名はそのまま文字列として残るので、意図しない置換は起きません。
- 管理画面の「ステップ一覧」には `→ 現在は "2026-08-27"` のように解決後の値が表示されます。
- **書き出した Playwright / Puppeteer スクリプトでも同じように動きます**。生成コードには同じ変換処理が埋め込まれ、`fill(V("{{date:YYYY-MM-DD}}"))` のように実行時に解決されます（変数を使っていない録画には埋め込まれません）。

## データを変えて繰り返し実行する（データ駆動）

同じシナリオを、入力値だけ変えて何度も流したい場合に使います。詳細ダイアログの「データ（繰り返し）」タブに表を登録すると、**1行につき1回シナリオを実行**します。

### 1. データを登録する

「CSV/TSV を貼り付けて取り込む」に Excel からコピーした表をそのまま貼れます（1行目が列名）。JSON を直接書いても構いません。

```json
[
  { "氏名": "山田太郎", "年齢": "30", "プラン": "pro" },
  { "氏名": "鈴木花子", "年齢": "25", "プラン": "free" },
  { "氏名": "佐藤次郎", "年齢": "41", "プラン": "max" }
]
```

### 2. ステップから列を参照する

値に `{{data.列名}}` と書くと、その行の値に置き換わります。

```json
{ "type": "input",  "selector": "#name", "value": "{{data.氏名}}" }
{ "type": "input",  "selector": "#age",  "value": "{{data.年齢}}" }
{ "type": "select", "selector": "#plan", "value": "{{data.プラン}}" }
{ "type": "input",  "selector": "#ref",  "value": "REF-{{date:YYYYMMDD}}-{{row:000}}" }
```

| 書き方 | 意味 |
| --- | --- |
| `{{data.列名}}` | 現在行のその列の値（`{{data:列名}}` とも書けます） |
| `{{row}}` / `{{row:000}}` | 何行目か（1 始まり、0埋め可） |

- 列名は**大文字小文字を区別**します。日本語の列名も使えます。
- 存在しない列を参照した場合は `{{data.○○}}` のまま画面に入力されるので、間違いにすぐ気づけます。データタブの表でも、その行に無い列は赤く表示されます。
- 各行の開始時に**開始URLへ戻ってからやり直す**ので、前の行の入力は残りません。
- 日付と `{{seq}}` は実行全体で固定、`{{row}}` だけが行ごとに変わります。行ごとに一意な値がほしい場合は `{{seq}}-{{row}}` のように組み合わせてください。
- 再生の進捗は「1/3 行目: 氏名=山田太郎 …」のように行ごとに区切って表示されます。
- 書き出したスクリプトもループになります（Playwright は行ごとに 1 テスト、Puppeteer は `for` ループ）。

## 待ち時間の設定（遅いサーバー・リロード時）

- **記録中のリロード**: ページを再読み込みしても記録は継続します（content script が読み込み時にセッション状態を問い合わせて自動的に復帰します）。ただし同一URLへのリロードそのものはステップとして記録されません。
- **自然遷移の尊重**: クリックによって既に目的の URL へ遷移していた場合、`navigate` ステップでは再遷移しません。これにより POST 結果画面などを壊しません。
- 上限を超えた場合はそのステップのみ「失敗」と表示し、後続のステップは続行します。

設定は 3 段階で解決され、下にあるものほど優先されます。

### 1. 全体設定（管理画面の「⚙ 設定」）

| 項目 | 既定値 | 用途 |
| --- | --- | --- |
| ページ読み込み待ち上限 | 60000ms | サーバー応答が遅いサイトで延ばす |
| 要素の出現待ち上限 | 8000ms | 描画が遅い画面で延ばす |
| ステップ間の待ち | 350ms | アニメーションが多い画面で延ばす |
| 失敗時のリトライ回数 | 3 | 遷移と重なった失敗の再試行回数 |

### 2. 録画ごとの設定

詳細ダイアログの「この録画の設定」タブで、項目ごとに「全体設定に従う」か「この録画だけの値」かを選べます。

- チェックを外した項目だけがこの録画の設定として保存され、残りは全体設定を引き継ぎます。
- 引き継いでいる項目は、あとから全体設定を変えれば自動的に追従します。
- 個別設定を持つ録画は、タブ名が「この録画の設定 ●2」のように表示されます。
- 「すべて全体設定に戻す」で個別設定を解除できます。

JSON タブから直接書いても同じです。

```json
{
  "startUrl": "https://example.com/",
  "settings": { "pageLoadTimeoutMs": 180000 },
  "steps": []
}
```

### 3. ステップごとの指定（特定の画面だけ遅い場合）

JSON の各ステップに直接書けます。

| キー | 意味 |
| --- | --- |
| `"timeoutMs": 120000` | このステップの要素待ちだけ延ばす |
| `"waitBeforeMs": 3000` | このステップの実行前に待つ |
| `"optional": true` | 失敗しても「警告」扱いで続行する |
| `"disabled": true` | このステップを飛ばす（削除せず一時的に無効化） |

さらに、待機専用のステップを差し込めます。

```json
{ "type": "wait", "ms": 5000 }
{ "type": "waitForSelector", "selector": "#result-table", "timeoutMs": 300000 }
```

重いバッチ処理の完了を待つ場合は、固定秒数の `wait` より、完了時に現れる要素を `waitForSelector` で待つほうが安定します。これらは Playwright / Puppeteer 出力にもそのまま反映されます。

## 既知の制限

- 記録は 1 タブに限定されます（記録開始後に別タブへ切り替えても、そのタブの操作は記録されません）。
- クロスオリジンの iframe は、その位置を特定できないため記録・再生が不完全になります。
- ドラッグ&ドロップは HTML5 の drag イベントを使う実装のみ対応です（mousedown/mousemove で自作されたものは未対応）。
- パスワード欄（`type="password"`）の入力値は `<PASSWORD>` としてマスクされ、実際の値は保存されません。
- セレクタは `data-testid` / `id` / `name` / `aria-label` / CSS パスの優先順で自動生成されるため、動的な DOM 構造のページでは再現性が下がる場合があります。
- 再生（リプレイ）機能は簡易実装であり、複雑な SPA やアニメーション待ちが必要なページでは失敗する場合があります。その場合は出力した Playwright / Puppeteer スクリプトを Node.js 環境で実行することを推奨します。
